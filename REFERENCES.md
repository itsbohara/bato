## Demonstrated reference states

- New Tab connection suggestions, combined URL/search/chat routing, contextual chat composer and tab/file picker.
- Apps catalog, connection preferences, Slack prompt and connected account controls. Slack was connected after explicit user confirmation; automatic connection of other logged-in apps remained off.
- Tabs settings: link-based groups, meeting groups, emoji, layout and cleanup controls. Settings were inspected without changing these preferences.
- A group created by Command-clicking a public link. Its first capture shows the name loading; later captures show the generated name. This demonstrates link-based grouping and naming, not a global operation that clusters all existing tabs by similarity.
- A completed public-page chat answer and its visible feedback/copy controls. After the user confirmed Slack access, a narrowly scoped read-only channel query returned an answer with an Open in Slack source link. This is observed UI behavior, not a network audit or proof of complete retrieval scope. No Slack message-writing action was requested or performed by the operator.
- A split containing two loaded public pages, with independent toolbars and a focused-pane border.
- Account, Profiles, Privacy, Skills/editor, Shortcuts, Advanced settings, Profile switcher, recent-tab and chat-history surfaces.

The private index distinguishes intermediate/loading states, final results and missing captures. Native menu screenshots and some coordinate actions were unavailable through computer control; one Tabs menu is retained as accessibility text only. Group collapse/rename, divider resizing, all provider/generation modes, meeting automation and every connected-app result are not exhaustively captured. This is a growing reference library, not a claim that every possible Dia state has been inspected.
